# Vocabulário Cearense — Referência Completa

Carregar quando precisar de vocabulário específico para interpretar ou falar cearês.

---

## Interjeições (não são agressividade — são emoção)

- **OXENTE / EITA / ARRE-ÉGUA** → espanto, surpresa
- **AGORA PRONTO! / AGORA DEU!** → indignação
- **MISERICÓRDIA** → pena ou espanto exagerado
- **MACHO** → marcador de ênfase ("macho, que calor!") — mais comum no CE do que "rapaz"
- **RAPAZ** → alternativa a "macho", mesmo uso
- **VISSE?** → "entendeu?" (busca confirmação)
- **APOIS** → "então" / "pois é"
- **AH, UMA JAULA!** → "que besteira!"
- **PAI D'ÉGUA** → o maior elogio — "isso é pai d'égua!" = extraordinário, incrível
- **ARRE-DIABO** → irritação, dor ou admiração conforme o tom
- **VIXE / VIXE MARIA** → susto, aflição ("vixe Maria, que aperreio!")
- **ARMARIA** → espanto, admiração — redução de "Ave Maria"
- **EITA PIULA!** → espanto, admiração
- **IEEEEEI!** → a vaia cearense — não é alegria, é zoação/deboche
- **VALHA** → espanto/surpresa, igual a "nossa" ou "vixe"
- **CUMA?** → "como?", pedido de repetição

## Pessoas e tratamento

- **CABRA** → homem, cara (sem ofensa). "Cabra bom" = pessoa boa
- **MAINHA / PAINHO** → mãe / pai
- **BICHIM** → tratamento carinhoso pra criança ou animal
- **TABARÉU / BERADEIRO** → matuto, do interior
- **PARICEIRA** → amigo, parceiro (geralmente feminino)

## Estados e qualidades

- **ARRETADO(A)** → o maior elogio. Ótimo, excelente, o máximo
- **ABESTADO** → bobo, tolo (forma mais comum de "abirobado")
- **ABIROBADO** → bobo, tolo, sem juízo (vem de "biroba" = égua)
- **BAQUEADO** → fraco, adoentado
- **DANADO** → travesso, inquieto
- **TRUBISCADO** → levemente bêbado
- **ZERADO** → novo, sem uso
- **ARRIADO** → apaixonado. "Arriado dos quatro pneus" = completamente apaixonado
- **APERREADO** → perturbado, estressado, sofrido
- **ESTURRICADO** → muito seco, ressecado (comida queimada, pele seca no sol)
- **AFOLOZADO** → frouxo, alargado, estragado
- **MISERENTO** → miserável, azarado, sem graça
- **AZARENTO** → azarado, sem sorte
- **TABACUDO** → bobo, sem noção, pateta
- **PAMONHA** → pessoa trouxa, fácil de enganar

## Ações e verbos

- **ABRIR** → ligar (aparelho). "Abre a luz" = liga a luz
- **ALUIR** → mover-se. "Se alui!" = se mexa
- **ARRIBAR** → levantar, erguer
- **BATER FOFO** → furar encontro
- **ACUNHAR** → chegar junto
- **ARIAR** → esfregar/polir com areia ("vai ariar as panelas")
- **PASTORAR** → vigiar, espreitar, tomar conta
- **ARRUDIAR** → dar a volta, contornar; também = mandar embora
- **CHINELAR** → correr, andar muito rápido ("eu chinelei!")
- **COISAR** → verbo coringa quando não se lembra a palavra certa
- **GAZEAR** → matar aula, se ausentar sem avisar
- **ARENGAR** → brigar, arrumar confusão. Quem briga muito = arengueiro

## Situações e estados

- **ZOADA/ZUADA** → barulho
- **DANAÇÃO** → travessura, confusão, bagunça
- **TABOCADA** → erro grande e irrecuperável
- **LERO-LERO** → conversa fiada
- **CANGAÇO** → confusão generalizada, briga
- **BABAU** → acabou, se foi, perdido
- **PITIÚ** → cheiro ruim, fedorento
- **CAMBITO** → pernas finas
- **LAREARENTO** → cheio de lero-lero, conversa fiada
- **BONEQUEIRO** → quem gosta de criar confusão por pouco
- **RACHA** → pelada, futebol informal
- **REBOLAR NO MATO** → jogar fora ("rebola essa blusa no mato")
- **AI DENTO** → "sai fora", "vai se danar"
- **BAIXA DA ÉGUA** → lugar muito longe; pra mandar embora
- **TÁ COM A GASTURA** → mal-estar, enjoo, sensação ruim

## Comida e cultura

- **MUGUNZÁ** → prato de milho branco (pede "mugunzá", num "canjica")
- **PANELADA** → prato com tripa e bucho — culinária raiz
- **PÃO D'ÁGUA** → pão de massa grossa típico do Ceará
- **ARRASTA-PÉ** → forró, festa de dança típica nordestina
- **PAPANGU** → mascarado de festa junina; por extensão, pessoa tola

## Marcadores de discurso

- **NOIS** → nós — "nois vai", "nois corrige mermo"
- **MERMO / MEMO** → mesmo — "agora mermo", "é isso mermo"
- **HORA POIS PRONTO** → resignação/determinação: "chega, vamo lá então"
- **VÁ NUM PÉ E VOLTE NOUTRO** → vai e volta rápido

## Ditados e expressões

- PASSARINHO QUE ANDA COM MORCEGO, DORME DE CABEÇA PRA BAIXO → sobre más companhias
- QUEM NUNCA COMEU MELADO, QUANDO COME SE LAMBUZA → sobre quem não tem costume
- DEIXOU O CABO DA BOTA NA BAIXA DA ÉGUA → foi pra muito longe, sumiu
- TÔ CHEI DOS PAU → muito bêbado
- ARIADO, VAI CATAR COQUINHO! → pessoa desnorteada, sem rumo
- APETRECHADA DEMAIS → muito bonita, bem dotada
- MIOLO DE POTE → pessoa sem importância, sem noção
- DIABEISSO, HOMEM! NUM FRESQUE NÃO! → "para com essa brincadeira"
- ARRE-ÉGUA, QUE CALOR DA MOLESTA! → espanto/irritação com algo intenso
- VEM PRA CÁ, TÁ CORRENDO FROUXO! → tem em abundância, sobra demais
